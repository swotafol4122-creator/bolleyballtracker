# バレー記録 DATA ver.6

バレーボールの試合データを、スマホ・iPad のタップだけで記録・集計するツールです。
`DATA_ver_5.xlsm` のマクロ（コート入力・成績表・コース図）を、計算式そのままで移植しています。

Excel のスマホ版・iPad 版は VBA を実行しないため、元のブックはモバイルでは動きません。
このアプリはブラウザだけで動き、記録は **そのまま Excel に貼り付けられる形** で取り出せます。

---

## 公開のしかた（GitHub Pages）

「ホーム画面に追加」は **https:// のページでないと使えません。**
ダウンロードしたファイルを直接開いても追加できないので、まず GitHub Pages に置きます。

1. GitHub で新しいリポジトリを作る（名前は自由。**Public** を選ぶ）
2. **Add file → Upload files** で、このフォルダの中身を **リポジトリの一番上の階層に** 全部アップロード

   ```
   index.html
   manifest.webmanifest
   sw.js
   icon-192.png
   icon-512.png
   apple-touch-icon.png
   .nojekyll
   ```

3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** / **/(root)** → **Save**
4. 1〜2 分後に `https://ユーザー名.github.io/リポジトリ名/` が公開される

### ホーム画面に追加
- **iPhone / iPad**：**Safari** で URL を開く → 共有ボタン（□に↑）→ **ホーム画面に追加**
- **Android**：Chrome で URL を開く → **︙** → **アプリをインストール**

追加後はアイコンから全画面で起動し、一度開けば **電波のない体育館でもオフラインで動きます**。

## 記録のしかた

画面は **スクロールなしで完結** します。上がコート、下が操作パネルです。

1. **選手** を押す（名簿に入れた人だけ出ます）
2. **スキル** を押す
3. **コートを押す** → 指を離さず滑らせると **拡大鏡** が出るので、狙ったマスで離す
   - 1 点目＝始点、2 点目＝終点
   - ブロックを選ぶと自動で 3 点入力（2 点目＝タッチ点）。手動で切り替えるときは「コース n/2」のチップを押す
   - 置いたあとの点は、その点を押し直せば動かせます
4. **評価（# + ! / - =）** を押すと記録されます

- 得点なら画面が緑、失点なら赤に一瞬光ります（振動も設定でオン）
- 記録すると **次に来やすいスキルが先に選ばれます**（レセプション→REアタック、サーブ→ディグ など）
- **コース入力は既定で任意**です。成績表は座標を使わないので、忙しいときは評価だけで記録できます
  （設定で必須にもできます）
- 相手のミスなどは「+1 / −1」で 1 タップ記録

### 直したいとき
**一覧タブ** で行を押すと、選手・スキル・トス・打ち方・評価・ローテを直せます。削除もできます。
途中の 1 本を消しても、**そのセットのスコアは全部自動で計算し直されます。**

## Excel への戻しかた

**設定タブ → 「Excelへコピー」** を押す → Excel の「データ」シートの **A2 を選んで貼り付け**。
これだけです。iPad の Excel でもこれが一番速いです。

ファイルで渡したいときは **追記用CSV**（見出しなし／A2 以降に貼る用）か
**見出し付CSV** を使ってください。列順・列数は元のブックと同一です。

```
始点ｘ, 始点y, 終点ｘ, 終点ｙ, タッチ点ｘ, タッチ点y, スキル, 自チーム, 相手チーム,
サーブ, トス, スパイク, 評価, 自チーム(得点), 相手チーム(得点), セット数, ローテーション
```

貼り付けたあとは、ブックの「成績」「コース」ボタンがそのまま使えます。

### 複数人で記録するとき
元ブックの入力シート 4 枚と同じ運用ができます。
各自の端末で記録 → それぞれ CSV を書き出し → 1 台で
**設定タブ → CSV / JSON を読み込む** で合流させてから貼り付けてください。

## 画面の説明

| タブ | 中身 |
|---|---|
| **記録** | コート＋操作パネル。ここだけで試合が回ります |
| **一覧** | 全記録の一覧。行を押すと修正・削除。得点のみ表示、Excelへコピーも |
| **成績** | 元マクロ `CreateStatsReport` と同じ 48 列の成績表（セット別／全セット合算） |
| **コース図** | スキル・トス・結果・セット・選手で絞り込み、選手ごとに矢印表示 |
| **設定** | 名簿、動作の切り替え、書き出し、読み込み、セット・試合の操作 |

コース図の色は元マクロと同じです。
強打＝赤／軟打＝青／フェイント＝緑／プッシュ＝紫、点線＝ブロック・ワンタッチ。

## 設定でできること

| 項目 | 既定 | 内容 |
|---|---|---|
| コース入力を必須にする | オフ | オンにすると座標なしでは記録できません |
| 次のスキルを先に選んでおく | オン | ラリーの流れから予測して先に選択します |
| ゾーン番号を表示 | オン | コートに 1〜6 の位置番号を薄く出します |
| 画面を消さない | オン | 試合中スリープしません |
| 記録時に振動 | オン | 得点・失点で長さが変わります（Android のみ） |
| 相手選手も記録する | オフ | 相手の名簿ボタンを記録画面に出します |

## iPad・タブレット

横向きにすると **左がコート、右が操作パネル** の 2 画面になります。
コートが大きくなるので、コース入力はこちらが正確です。

## 更新のしかた

`index.html` を差し替えて commit すれば、次回起動時に自動で新しくなります。
すぐ反映したいときは **設定タブ → 最新版に更新する**。

それでも古いままなら、`sw.js` の 3 行目

```js
const CACHE = 'volley-ver6-1';
```

の数字を増やして commit してください。全端末に配られます。

## データの保存先

記録は端末内（ブラウザのローカル保存）に自動保存されます。サーバーには何も送られません。
端末を変えるときは **設定タブ → バックアップ（JSON）** を書き出して、新しい端末で読み込んでください。

> ブラウザの履歴・サイトデータを消すと記録も消えます。試合が終わったら Excel へコピーするか CSV を書き出しておくのが安全です。

## 座標について

コートの座標は元ブックとまったく同じです。

- 描画範囲：列 2〜52（51 マス）× 行 6〜83（78 マス）／1 マス = 1/3 m
- コート内：列 14〜40 × 行 18〜71
- ネット：行 44 と 45 の境／アタックライン：行 35-36、行 53-54 の境
