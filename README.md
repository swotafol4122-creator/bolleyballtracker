# バレー記録 DATA ver.5

バレーボールの試合データを、スマホ・iPad のタップだけで記録・集計するツールです。
`DATA_ver_5.xlsm` のマクロ（コート入力・成績表・コース図）を、そのままの計算式で移植しています。

Excel のスマホ版・iPad 版は VBA を実行しないため、元のブックはモバイルでは動きません。
このアプリは iPhone / iPad / Android のブラウザで動き、記録は **データ追記用CSV** として書き出して、
元のブックの「データ」シートにそのまま貼り付けられます。

---

## 公開のしかた（GitHub Pages）

「ホーム画面に追加」は **https:// のページでないと使えません。**
ダウンロードしたファイルを直接開いても追加できないので、まず GitHub Pages に置きます。

1. GitHub で新しいリポジトリを作る
   - リポジトリ名は何でもよい（例：`volley-tracker`）
   - **Public** を選ぶ（Private だと Pages が使えないプランがあります）
   - 「Add a README file」はチェックしなくてよい

2. このフォルダの中身をすべてアップロードする
   - リポジトリの **Add file → Upload files**
   - 下の 7 ファイルをまとめてドラッグ＆ドロップ → **Commit changes**

   ```
   index.html
   manifest.webmanifest
   sw.js
   icon-192.png
   icon-512.png
   apple-touch-icon.png
   .nojekyll
   ```

   > フォルダを作らず、リポジトリの一番上の階層に置くこと。

3. Pages を有効にする
   - **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** / **/(root)** → **Save**

4. 1〜2 分待つと URL が表示される

   ```
   https://ユーザー名.github.io/リポジトリ名/
   ```

## ホーム画面に追加する

### iPhone / iPad
1. **Safari** で上の URL を開く（Chrome ではなく Safari）
2. 下の **共有ボタン**（□に↑）をタップ
3. **「ホーム画面に追加」** → 追加

### Android
1. Chrome で URL を開く
2. 右上の **︙** → **「アプリをインストール」** または「ホーム画面に追加」

追加後はアイコンから起動でき、アドレスバーのない全画面で動きます。
一度開けば **電波のない体育館でもオフラインで起動** します。

---

## 使い方

1. **設定タブ**でチーム名と名簿を入力（上段＝1〜6・Li、下段＝控え）
2. **記録タブ**で　選手 → スキル → コートを 2 タップ → 評価ボタン
   - ワンタッチ／ブロックは 3 タップ（2 点目がタッチ点）
   - 画面下の帯に「いま何を選んでいるか」と「あと何点タップが要るか」が出ます
3. **成績タブ**：元の `CreateStatsReport` と同じ 48 列の成績表（セット別／全セット合算）
4. **コース図タブ**：スキル・トス・セット・選手で絞り込んで矢印表示
   - 色は元マクロと同じ（強打=赤／軟打=青／フェイント=緑／プッシュ=紫、点線=ブロック・ワンタッチ）
5. 試合後、**設定タブ → データ追記用CSV** を書き出し、
   PC の `DATA_ver_5.xlsm` の「データ」シート **A2 以降** に貼り付ける
   → 既存の「成績」「コース」ボタンがそのまま使えます

### 複数人で記録するとき
元ブックの入力シート 4 枚と同じ運用ができます。
各自の端末で記録 → それぞれ CSV を書き出し → 1 台で
**設定タブ → CSV / JSON を読み込む** で合流させてから貼り付けてください。

## 更新のしかた

`index.html` などを差し替えて commit すれば、次回起動時に自動で新しくなります。
すぐ反映したいときは、アプリの **設定タブ → 最新版に更新する**。

キャッシュが残って更新されない場合は、`sw.js` の 1 行目

```js
const CACHE = 'volley-ver5-1';
```

の数字を `-2`, `-3` … と増やして commit してください。全端末に配られます。

## ファイル構成

| ファイル | 中身 |
|---|---|
| `index.html` | アプリ本体（HTML・CSS・JS すべて 1 ファイル） |
| `manifest.webmanifest` | アプリ名・アイコン・全画面表示の設定 |
| `sw.js` | オフライン起動用のキャッシュ |
| `icon-192.png` / `icon-512.png` | ホーム画面・インストール用アイコン |
| `apple-touch-icon.png` | iOS ホーム画面用アイコン（180px） |
| `.nojekyll` | GitHub Pages のビルドを省略する目印 |

## データの保存先

記録は端末内（ブラウザのローカル保存）に自動保存されます。サーバーには何も送られません。
端末を変えるときは **設定タブ → バックアップ（JSON）** を書き出して、新しい端末で読み込んでください。

> ブラウザの履歴・サイトデータを消すと記録も消えます。試合が終わったら CSV を書き出しておくのが安全です。

## 座標について

コートの座標は元ブックとまったく同じです。

- 描画範囲：列 2〜52（51 マス）× 行 6〜83（78 マス）／1 マス = 1/3 m
- コート内：列 14〜40 × 行 18〜71
- ネット：行 44 と 45 の境／アタックライン：行 35-36、行 53-54 の境

書き出す CSV の列順も元の「データ」シートと同一（17 列）です。

```
始点ｘ, 始点y, 終点ｘ, 終点ｙ, タッチ点ｘ, タッチ点y, スキル, 自チーム, 相手チーム,
サーブ, トス, スパイク, 評価, 自チーム(得点), 相手チーム(得点), セット数, ローテーション
```
